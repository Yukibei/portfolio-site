# 恐龙跑酷网页集成说明

## 1. 来源与目标

网页游戏基于用户提供的本地工程 `E:\archives\dino_material_game` 改造。原工程使用 Pygame，包含完整的角色帧、障碍物、背景、音效与游戏规则。

本次不嵌入 Python 桌面窗口，也不使用循环动画伪装玩法，而是将规则重写为 React 19 可复用的 Canvas 游戏内核。

## 2. 页面入口

- 首页人物终局：签名与能力标签下方的小恐龙是主要入口。点击后在人物段下方展开紧凑游戏，并自动滚动到游戏面板。
- 任意不存在的地址：404 页面内嵌紧凑版游戏。
- `/lab`：Dino Runner 项目标记为 `Homepage game` 并链接到首页游戏锚点。
- `/lab/dino-runner`：兼容旧链接，自动重定向到 `/#dino-runner`。

首页与 404 使用同一组件和同一套本地最高分，不维护两份游戏逻辑。首页保留原有进站恐龙加载动画；该动画只负责加载反馈，不替代真实游戏。

## 3. 已实现规则

- 开始、跳跃、下蹲、快速下落、暂停、继续与重新开始。
- 随机仙人掌与翼龙；翼龙达到分数门槛后出现。
- 实时碰撞检测、连续计分和速度递增。
- 每 100 分触发里程碑音效，每 500 分切换昼夜。
- 最高分写入浏览器 `localStorage`。
- 游戏离开页面或浏览器进入后台时自动暂停。
- 桌面键盘、鼠标点击和移动端触摸均可操作。
- 音效默认关闭，由访问者主动开启。

## 4. 代码结构

- `web/components/dino/gameAssets.ts`：图片和音频素材清单与预加载。
- `web/components/dino/gameEngine.ts`：状态机、物理、障碍生成、计分与碰撞。
- `web/components/dino/gameRenderer.ts`：Canvas 背景、角色、障碍、分数与昼夜渲染。
- `web/components/dino/DinoRunnerGame.tsx`：React 生命周期、输入、音效、响应式画布和控制栏。
- `web/public/dino/`：从原工程复制的 51 个素材文件，共约 561 KB。

各动态语言文件保持在 300 行以内；游戏逻辑不依赖新增第三方库。

## 5. 验证

统一使用 `scripts/verify/portfolio-site/run.sh`。其中 `game_audit.py` 会分别在桌面端和移动端验证：

- 素材加载完成。
- 首页签名下的小恐龙能够展开游戏。
- 开始、计分与跳跃有效。
- 障碍碰撞能够进入游戏结束。
- 重开、暂停和继续有效。
- 旧独立地址能够重定向到首页游戏。
- 页面没有横向溢出或浏览器控制台错误。

验证截图与报告输出到 `logs/visual-audit/`。
